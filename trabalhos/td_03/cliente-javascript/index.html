Membros

    Mensagens recebidas

      Nenhuma mensagem ainda. Faça uma saída de estoque ou publique algo.

      Passagem por valor × por referência

      Por valor

      Você recebe uma cópia do item em JSON. Alterar a cópia não muda o objeto do servidor.

      Por referência

      O pedido fica no servidor. Dois proxies com a mesma referência atuam no mesmo objeto.

      Escolha uma demonstração.

      Protocolo requisição-resposta

      Cada chamada remota é uma requisição HTTP com corpo JSON (>>>) e volta como uma resposta (<<<) com o mesmo X-Request-Id.
